## Question
4. You discover a credential was accidentally committed to the repository. What is the correct remediation?

## Options
Option 1 : Delete the file in a new commit and consider the issue resolved, since the file no longer appears in the latest version

Option 2 : Rename the file so it can't be found, since renaming removes it from normal repository browsing

Option 3 : Add the file to .gitignore going forward, since this prevents the same file from being committed again

Option 4 : Rotate/revoke the exposed credential first, then remove it from history — deleting the file in a new commit alone is not sufficient

## Answers
Option 4 : 2
