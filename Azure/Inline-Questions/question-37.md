## Question
7. True or False: Anyone with push access to a repository can bypass a branch policy (such as a required pull request review) by default, without needing any additional permission.

## Options
Option 1 : True

Option 2 : False

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct — False. Branch policies are enforced for everyone by default once configured; bypassing them requires a separate, explicitly granted permission ("Bypass policies when completing pull requests" or similar), not just ordinary push access.
