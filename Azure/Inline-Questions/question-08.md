## Question
3. What is the primary purpose of ksqlDB in a Kafka-based pipeline?

## Options
Option 1 : To encrypt messages at rest on the broker, protecting stored data from unauthorized access

Option 2 : To act as a backup broker, taking over automatically if the primary broker fails

Option 3 : To replace Zookeeper as the cluster's coordination and metadata management service

Option 4 : To write continuous, SQL-like queries directly against streaming data, without writing custom consumer code

## Answers
Option 4 : 1

## Correct Answer Feedback
Correct. ksqlDB lets you filter, aggregate, and transform streaming data using familiar SQL syntax, running continuously against a topic — it's not a coordination service, an encryption layer, or a broker replacement.
