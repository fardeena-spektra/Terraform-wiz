## Question
2. A pull operation reports a merge conflict. What is the correct first step?

## Options
Option 1 : Delete your local branch and start over, since a fresh clone avoids having to deal with the conflict directly

Option 2 : Review the conflicting sections, resolve them manually (or with a merge tool), then commit the resolution

Option 3 : Force push your local branch to overwrite the remote, since your local changes are usually the ones that matter

Option 4 : Ignore the conflict and continue working, since Git will resolve it automatically once you push again

## Answers
Option 2 : 2
