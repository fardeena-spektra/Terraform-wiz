## Question
4. An OpenShift Route (or Kubernetes Ingress) returns 503 errors, while the underlying pod shows as Running. What should you check next?

## Options
Option 1 : Whether the Service selector correctly matches the pod's labels, and whether the pod is passing its readiness probe

Option 2 : Whether the pod's image tag has a typo, since this is a common cause of unexpected routing errors

Option 3 : Whether the namespace has been deleted, which is often the first thing worth ruling out with a 503

Option 4 : Whether the cluster version is outdated, since older versions are frequently blamed for routing-layer issues

## Answers
Option 1 : 2
