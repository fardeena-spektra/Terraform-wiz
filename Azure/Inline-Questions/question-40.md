## Question
10. True or False: When a pipeline environment has an approval check configured, the pipeline will pause before deploying to that environment and wait for a designated approver to sign off before continuing.

## Options
Option 1 : True

Option 2 : False

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct — True. Approval checks on an environment are exactly this kind of gate — the pipeline run pauses at that stage until an approver (or one of a defined group of approvers) explicitly approves or rejects it, which is commonly used to require sign-off before a production deployment.
