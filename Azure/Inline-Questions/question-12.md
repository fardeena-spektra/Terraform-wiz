## Question
2. A Kibana search for a known field value returns no results, even though the index clearly contains matching documents. What is the most likely cause?

## Options
Option 1 : The cluster needs to be restarted, since a stale cluster state can cause searches to miss existing documents

Option 2 : A field mapping or analyzer mismatch is causing the search to not match the stored value as expected

Option 3 : Elasticsearch has silently deleted the matching documents, likely due to an index lifecycle policy

Option 4 : Kibana can only search the most recent 100 documents by default, hiding older matching records

## Answers
Option 2 : 2
