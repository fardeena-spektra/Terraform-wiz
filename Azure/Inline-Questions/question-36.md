## Question
6. True or False: Azure DevOps YAML pipelines are defined as code and stored in the repository itself, unlike Classic pipelines, which are configured through the Azure DevOps UI and not version-controlled alongside the code.

## Options
Option 1 : True

Option 2 : False

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct — True. YAML pipelines live in a file (typically azure-pipelines.yml) inside the repository, so pipeline changes go through the same review and history as code changes. Classic pipelines are built and stored through the UI, separate from the repository.
